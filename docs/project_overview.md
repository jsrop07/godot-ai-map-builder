# 프로젝트 개요

## 최종 제품

별도 웹 맵 편집기가 아니라 Godot EditorPlugin으로 구현한다.

## 사용자 흐름

1. 사용자가 Godot 에디터에서 Placeholder 또는 실제 에셋을 배치한다.
2. Godot 채팅 Dock에 자연어 요청을 입력한다.
3. 플러그인이 현재 맵 JSON과 선택 영역 정보를 FastAPI 서버로 전송한다.
4. 백엔드가 자연어 요청을 분석한다.
5. 에셋 RAG와 스타일 RAG로 적절한 에셋과 배치를 검색한다.
6. LangGraph가 후보 생성, 검증, 보정, 랭킹을 수행한다.
7. 백엔드는 제한된 작업 명령 JSON을 반환한다.
8. Godot가 PackedScene을 직접 배치한다.
9. 사용자가 후보를 비교하고 적용한다.

## 핵심 원칙

- LLM이 .tscn 텍스트를 직접 생성하지 않는다.
- Godot에 등록된 PackedScene만 배치한다.
- AI 명령은 허용된 작업 목록으로 제한한다.
- 충돌, 접근성, 통로, 이동 경로를 규칙 기반으로 검증한다.
- 선택 영역 밖의 오브젝트는 수정하지 않는다.
